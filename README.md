# 模型匣

> 给 Hana 的模型供应商加开关；~~排序调整~~（等以后 Hana 开放权限后再支持）。关掉不用的供应商，主对话框的模型菜单立刻清爽；随时能再打开，配置原样保留。

## ⚠️ 先看风险

- 这个插件会**直接读写 Hana 的供应商配置文件**（`provider-catalog.json`），所有改动都有校验和快照保护，但建议动之前心里有数
- 插件会在本机读取 Hana 自己的本机凭据文件，**只为在 127.0.0.1 本机调用 Hana 自带的管理接口**，不会把任何配置或密钥发到网上
- ~~供应商 / 模型排序：拖动后保存调整结果，菜单跟着同步~~（等以后 Hana 开放权限后再支持）

## 这是干什么的？

我做了个小匣子，专门收拾 Hana 主对话框那个越来越挤的模型菜单。

供应商配多了，菜单里一长串全是模型，找常用的要翻半天。模型匣就是干这个的：把不常用的供应商**收进匣底**（配置、密钥原样保留，随时放出来），~~把剩下的**拖成你顺手的顺序**~~（等以后 Hana 开放权限后再支持）。

它不动你的任何模型配置，只做"可见性"；~~"顺序"调整~~（等以后 Hana 开放权限后再支持）暂不计入当前可用功能，改坏了也能一键恢复原样。

## 它能做什么

- 🔌 **一家一开关**：关掉的供应商立刻从模型菜单消失，配置和密钥原样保留
- ~~🔀 **供应商排序**：拖动调顺序，保存后实时同步~~（等以后 Hana 开放权限后再支持）
- ~~🔀 **模型排序**：展开供应商，拖动具体模型调顺序~~（等以后 Hana 开放权限后再支持）
- 🕵️ **正在使用保护**：正在用的供应商收不进去，先切走再说
- 📋 **运行时对账**：Hana 没采纳顺序时明确提示，不报喜不报忧
- 🔄 **检查更新**：页面一键对比 GitHub 最新版

## 安装 / 卸载

1. 从 Releases 下载 `moxingxia-vX.X.X.zip`
2. Hana 插件市场右上角「安装本地插件」选择 zip，或解压到插件目录
3. 重启 Hana，模型匣出现在插件列表里

卸载直接在插件管理里禁用或删除，不会残留配置。

## 隐私

- 全部数据存在本机，**没有任何外发**
- 读取 `server-info.json` 的本机 token，只用于 127.0.0.1 本机调用 Hana 管理接口
- 不收集任何统计信息，没有埋点

## 兼容性

- 支持 Hana **v0.449.0 及以上**（含 0.450）
- ~~已知限制：内置供应商的模型顺序仍按 Hana 内置目录展示，模型匣会提示"已保存但菜单没换"~~（等以后 Hana 开放权限后再支持）
- 在设置页对某家供应商重新"发现模型"并保存，可能把该家的模型列表~~（含你在模型匣里排的顺序）~~重写回默认
